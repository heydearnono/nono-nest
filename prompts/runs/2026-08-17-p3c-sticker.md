## 这一轮的四个判断

**「不许有计算」这条分层约束顺带修掉了一个静默的数据损坏。** 线上贴纸 id 是
`z(name, i) => st-${String(i).padStart(3,'0')}-${name}`（`:269915`），运行时由**下标**算。
`AGENTS.md` 第 3 节说 `data/` 零函数零判断零计算，所以 id 只能写死 ——
而写死之后线上那个缺陷就没了：`stickerCollection` 的键就是这些 id，
线上给 `mo` 排一次序，历史收藏册的每一个键都会对不上，**140 张全变「没抽到」
而不报任何错**。**规律：分层约束不只是整洁，它会挡掉一类「派生值当标识符」的错 ——
凡是「运行时算出来的东西被当成持久化的键」，都该问一遍这个算法会不会变。**

**同一句「顺序是规格」可以有强弱不同的三个理由，写下来的必须是理由不是结论。**
`characters.js` / `poems.js` 的顺序是教学序列（先学最常见的字、先背最浅的诗），
重排毁掉难度梯度；`stickers.js` 的顺序只是图鉴按类别分六段的排版，重排**只是显示变了**。
三份都写着「顺序即规格」，但本份最弱。头注释里点名了这个差别 ——
否则下一个人会因为那两份不可动而以为这份同样不可动，
于是一件本来可以做的事被一句抄来的话挡住。**规律：把同一句约束贴在第三份数据上时，
要写「为什么」不是「不许动」—— 三份的「为什么」不同，而结论看起来一样。**

**注入随机源与固定随机源，代价的形状完全不同。** 三个候选摆过：页面传 `random()`
（多一个参数、每条测试给假函数、还要拍板「传了坏函数怎么办」）、页面传 `nonce`、
**种子吃 `` `${日期键}|${已抽总次数}` ``**。选第三个的关键不是它更纯，
是那条代价**在界面上观测不到**：抽取是不可撤销的写入，抽完第 N 次就只能抽第 N+1 次，
没有「回到抽之前再抽一次」这条路径。而它在测试里是白拿的 —— 20 条测试**一条桩都没打**。
**规律：判断一条确定性代价该不该接受，问的不是「它是不是缺陷」，
是「有没有一条用户路径能观测到它」—— 观测不到的确定性是免费的可测性。**

**已抽总次数不落新字段，因为收藏册已经记着它了。** 种子的第二个分量是
`Object.values(收藏册)` 求和。再存一个计数器就是同一笔数据两个来源，
而两个来源必然会在某个路径上分叉（P3-b 的「进度每次现算，不存」同一条 ——
线上存 `medalProgress` 快照且解锁后不再更新，进度条永远停在解锁那一刻）。
**规律：加水位之前先问「它能不能从已有的数据求出来」——
能求出来的水位，落盘等于给自己造一个会过期的副本。**

## 这条 prompt 缺什么

**它没说 `0` 这个值该在哪一层被处理掉。** 线上页面用
`Object.keys(e).filter(t => e[t] > 0).length` 数收藏数（`:677950`）——
它自己承认收藏册里可能有 `0`，而加载时 `stickerCollection ?? 默认` 整份透传、
元素不收敛（`:272796`），所以脏值进来就一直在。可以在读取侧判 `> 0`（照抄线上），
也可以在收敛层把这些键**整条丢掉**。选后者，于是读取侧只剩「键在不在」一个判据。
**规律：一个「值可能是脏的」的问题，在收敛层解决掉之后，读取侧的判据数会减一 ——
而读取点通常不止一个，所以省下的不是一行。**

**它没说未知 id 该留还是该删，而两个方向各对一半。** 收敛层零 import，
认不出哪个 id 在 `data/stickers.js` 里登记过（与 `rewardFlags` 同一条）。
删了就是丢数据 —— 而万一那是本仓库还没登记的一张，删掉不可逆。留着只是没人读。
所以**收敛层留、读取侧忽略**，两层各配一条规格：`SAVE-25` 断言脏 id
**留在存档里**，`STICKER-06` 断言它**不出现在图鉴上**。少了后者，
一个「在收敛层就把脏 id 删掉」的实现也能全绿，而那个实现会丢数据。
**规律：「留着但不读」这类处置必须两层各一条规格 —— 一条证明留了，
一条证明没读。只写一条的话，两种相反的实现都能过。**

**它没提 140 格的界面会与既有页面抢结构。** 线上贴纸乐园是**奖励中心页里的一个
section**（`:685787`）。照搬会让 `reward.wxml` 从 69 行长到 250 行以上。
判据不是 P7 第三段那条（只读性 —— 抽贴纸是写入口），是**两块界面共用多少数据**：
奖励中心的四段共用同一份勋章余额与 `redemptions` / `achievements`，
而贴纸只共用**勋章余额一个数**。**规律：「拆不拆页面」在只读性之外还有第二条判据 ——
两块界面之间有多少数据要一起改。共用一个数的两块，永远不会因为同一个原因同时改。**

哪一条是先写的。** 下一轮从第一个勾开始就一条一条。

前四种是「删掉入口」「收拢到一处」「让一个前提消失」「不修但标出来」。

掉落粒子整件在「范围外」，所以那个缺陷连着它的载体一起没有了。
**这一种最不值得庆祝**：它不是判断的产物，是范围收缩的副产品。
但记下来有用 —— 下一轮若把粒子做回来，这个缺陷会跟着回来。
