## 实现要点

- 时段判断用连续的 `if (hour < N) return`，比区间数组更直白，5 个分支不值得抽象
- 入参校验放在函数开头，用 `Number.isInteger` 一次挡掉小数、字符串、负数、越界
- 页面层 `home.js:onLoad` 里调 `new Date().getHours()` 后传入，纯函数本身不碰时间
