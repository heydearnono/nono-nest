# 领域术语字典

> AI 在生成代码、文档、注释、测试名时**必须**使用本表中的词，不得自创同义词。
> 新增术语必须同步更新本文件（见 `AGENTS.md` 第 2 节）。
> 「禁用词」列出的是容易被自动生成的错误同义词，出现即视为不合规。

## 实体

| 中文     | 标识符     | 含义                         | 禁用词                                                  |
| -------- | ---------- | ---------------------------- | ------------------------------------------------------- |
| 蛋       | `egg`      | 宠物孵化前的形态             | `Egg` 之外的 `seed` / `cocoon`                          |
| 宠物     | `pet`      | 孵化后的主角，全局唯一       | `animal` / `creature` / `nono`（nono 是用户，不是宠物） |
| 宠物状态 | `petState` | 某一时刻宠物的完整可观测状态 | `status` / `petInfo` / `petData`                        |
| 存档     | `save`     | 落到 storage 的持久化数据    | `profile` / `record` / `db`                             |

## 数值

| 中文   | 标识符   | 取值                   | 含义                             | 禁用词                                     |
| ------ | -------- | ---------------------- | -------------------------------- | ------------------------------------------ |
| 饥饿度 | `hunger` | 0–100 整数，越大越饿   | 0 = 刚吃饱，100 = 最饿（封顶）   | `food` / `satiety` / `fullness` / `hungry` |
| 心情值 | `mood`   | 0–100 整数，越大越开心 | 100 = 最开心，0 = 最低落（保底） | `happiness` / `happy` / `emotion` / `joy`  |
| 亲密度 | `bond`   | 0–100 整数             | 长期累积，不随时间衰减           | `affection` / `love` / `intimacy`          |

注意饥饿度与心情值的方向相反：`hunger` 越大越差，`mood` 越大越好。这是刻意的（符合中文直觉），
写公式和断言时不要「统一」成同一方向。

## 时间

| 中文         | 标识符         | 含义                                   | 禁用词                               |
| ------------ | -------------- | -------------------------------------- | ------------------------------------ |
| 当前时刻     | `now`          | 毫秒时间戳，**必须由调用方传入纯函数** | `Date.now()` 直接调用、`currentTime` |
| 上次喂食时刻 | `lastFedAt`    | 毫秒时间戳                             | `feedTime` / `lastFeed`              |
| 上次陪玩时刻 | `lastPlayedAt` | 毫秒时间戳                             | `playTime` / `lastPlay`              |
| 离开时长     | `elapsedMs`    | 两个时刻之间的毫秒差                   | `duration` / `delta` / `diff`        |
| 衰减         | `decay`        | 数值随时间自然变差的过程               | `decrease` / `drop` / `reduce`       |

## 动作

| 中文 | 标识符   | 含义                               | 禁用词                                           |
| ---- | -------- | ---------------------------------- | ------------------------------------------------ |
| 孵化 | `hatch`  | 蛋变成宠物                         | `birth` / `spawn` / `create`                     |
| 喂食 | `feed`   | 降低饥饿度                         | `eat` / `giveFood`                               |
| 陪玩 | `play`   | 提高心情值                         | `interact` / `pet`（`pet` 是名词，不作动词）     |
| 睡着 | `asleep` | 长期未打开后进入的休眠表现，可恢复 | `dead` / `gone` / `lost`（产品明确不做负面终局） |

## Spec ID 区名

规格 ID 格式 `<AREA>-<NN>`，已分配的区名：

| 区名     | 覆盖范围         |
| -------- | ---------------- |
| `HUNGER` | 饥饿度计算与衰减 |
| `MOOD`   | 心情值计算与衰减 |
| `HATCH`  | 孵化流程         |
| `FEED`   | 喂食交互         |
| `PLAY`   | 陪玩交互         |
| `SAVE`   | 存档读写与默认值 |
| `GREET`  | 时段问候语       |

新增区名先加到本表，再在 `doc.md` 中使用。
